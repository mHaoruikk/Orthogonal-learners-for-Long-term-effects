Implementation of an LT-learner for long-term heterogeneous treatment effects by combining an experimental cohort (A,S,X, no Y) with an observational cohort (S,X,Y, no A). Includes synthetic and semi-synthetic data generators and nuisance-model cross-fitting.

## Quick start
1) Create an environment (Python ≥3.10) and install deps:
   pip install numpy pandas scipy scikit-learn xgboost torch hydra-core omegaconf matplotlib
2) Single-learner training entry points:
   - T-learner:   `python -m scripts.train_t_learner`
   - RA-learner:  `python -m scripts.train_ra`
   - IPW-learner: `python -m scripts.train_ipw`
   - LT-O family: `python -m scripts.train_lto` (use weight_type in the model config)

## Reproduce the synthetic PEHE results

The four overlap regimes reported in `notebooks/syn_result.ipynb` are
generated by `scripts/eval_syn.py`, which loops B replicates per dataset,
seeds the learners with `master_seed + b`, and writes a JSON summary to
`outputs/<dataset>_pehe_<backbone>.json`.

Run all four regimes (B=5, NN backbone, all 9 learners):

```
python -m scripts.eval_syn --dataset syn-low-outcome-overlap   --B 5 --master_seed 42
python -m scripts.eval_syn --dataset syn-low-treatment-overlap --B 5 --master_seed 42
python -m scripts.eval_syn --dataset syn-dual-overlap          --B 5 --master_seed 42
python -m scripts.eval_syn --dataset syn-healthy               --B 5 --master_seed 42
```

Each run writes `outputs/<dataset>_pehe_nn.json` and a log
`outputs/log_<dataset>_nn.txt`. The notebook
`notebooks/syn_result.ipynb` loads all four JSONs and prints the
sorted PEHE table per regime.

Useful flags:
- `--models RA-learner LO-learner ...` to restrict which learners run.
- `--no-nn_backbone` to use each model's stock cate_regressor instead of the torch_mlp swap.
- `--B 10 --master_seed 42` for more replicates.

All four `config/dataset/syn-*.yaml` files set `use_old_dgp: true`, which
selects the linear-in-X τ_S and the simpler `b(X,S) = sin(X0·X1) + X6² + X7
+ S + (S²)/4` form. Y is normalized to mean=0, std=1 inside `sample()`,
and `true_cate` is scaled accordingly.

## Configuration
Hydra config lives in `config/`. Defaults are set in `config/config.yaml`; override pieces via CLI, e.g. `dataset=setupB model=T-learner`. Key files:
- `config/dataset/*.yaml` – data generators (synthetic surrogate, semi-synthetic)
- `config/model/*.yaml` – learner + nuisance settings (logistic/xgboost, overlap weights, cross-fitting)
- `config/trainer/*.yaml` – train/val/test split fractions.

## Repository map
- `src/data/` data classes and generators (`synthetic.py` holds the Nie–Wager DGP and the `use_old_dgp` toggle)
- `src/model/` learners (T, RA, IPW, LT-O family with weight_type ∈ {identity, to, lo, dual, …}) and the cross-fitting `NuisanceFactory`
- `scripts/eval_syn.py` synthetic PEHE benchmark across replicates (used to produce `notebooks/syn_result.ipynb`)
- `scripts/train_*.py` single-learner training entry points
- `scripts/eval_gain_pehe.py`, `scripts/evaluate_ist_real.py` semi-synthetic / real-data benchmarks
- `notebooks/syn_result.ipynb` loads `outputs/syn-*_pehe_nn.json` and prints sorted PEHE tables
- `outputs/` benchmark JSON + logs
